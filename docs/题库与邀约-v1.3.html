完整题库

1. 收到任务：“拍一条你的极氪日常。”你脑子里先冒出：

  1. 傍晚那束光，落在车身上一定好看。
  2. 上周接朋友那一路，够讲一段了。
  3. 要不让后备厢里的东西当一次主角？
  4. 那个天天在用的功能，我想讲清楚。

2. 第一次和组员碰面，大家客气了三分钟。你更可能：

  1. “咱们先定个小目标，今天拍成什么？”
  2. “大家都想试哪一块？先聊聊。”
  3. “我先来，拍砸了你们就当花絮。”
  4. “你们有没有拍过什么特别离谱的现场？”

3. 刷到一条很火的同款车视频，你顺手点了收藏。最可能是因为：

  1. 它把一个功能讲得很明白。
  2. 这个玩法，我想换个角度试试。
  3. 这几个镜头，反复看还是觉得舒服。
  4. 这套拍法不复杂，下次真能用上。

4. 朋友口播卡了五遍，开始说“我不行”。你会先：

  1. “先歇一下，刚才有一句其实挺自然。”
  2. “你就跟我说，我接你的话。”
  3. “别背稿了，从你上次真的遇到那件事讲。”
  4. “换个位置试试，别让镜头贴这么近。”

5. 刚拍完一遍，发现根本没点录像。你的第一句更像：

  1. “没事，刚才算彩排，这遍更熟！”
  2. “等一下，先确认声音也开了。”
  3. “要不把这个翻车过程也拍进去？”
  4. “先看看大家累不累，再来一遍。”

6. 素材拍了一堆，剪到一半开始纠结。你最舍不得删的是：

  1. 没在脚本里，但特别像当天的那一小段。
  2. 为了这个光，等了好久才拍到的镜头。
  3. 少了它，前后就接不起来的那一步。
  4. 能让人一下明白功能怎么用的那几秒。

7. 想好的拍摄地点临时进不去。你更可能说：

  1. “旁边那条路挺有意思，换个拍法？”
  2. “附近还有两处，先去离得近的。”
  3. “人都在，先拍段聊天找找状态。”
  4. “先找个能坐的地方，别让大家干等。”

8. 视频发出去后，你最想收到哪条评论？

  1. “你这几个镜头，我来回看了好几遍。”
  2. “终于有人把这个说清楚了。”
  3. “看得很舒服，像朋友在跟我聊天。”
  4. “这段我懂，我也有过一模一样的经历。”

9. 组里说“这个点子有点冒险”。你通常会：

  1. “先试个十秒版本，看看有没有意思。”
  2. “我来演一下，你们看完再判断。”
  3. “我们还剩多久？能试就留点时间。”
  4. “我找几张参考图，大家先看那个感觉。”

10. 同一条片子有两个剪法，你更容易被什么说服？

  1. 看完会想知道后面还发生了什么。
  2. 出镜的人说：“这版更像平时的我。”
  3. 找个没看过素材的人，看哪版更容易懂。
  4. 有个没见过的处理，第一眼就记住了。

11. 离交片还有半小时，你最想再确认一遍：

  1. 字幕、参数、功能名，有没有说错。
  2. 导出、链接、交付格式，能不能顺利交上。
  3. 封面和开头三秒，第一眼够不够好看。
  4. 把开场念一遍，听着像不像平时说话。

12. 拍摄结束，哪句话最让你想和这群人再合作？

  1. “今天大家都挺自在，没有谁一直硬撑。”
  2. “下次那个新点子，咱们真可以试试。”
  3. “今天这些小插曲，我能记很久。”
  4. “刚才你接的那句话，真的太好笑了。”
