完整题库

1. 给爱车拍条视频，你最想拍什么？

  1. 夕阳下，爱车最好看的角度
  2. 今天用车遇到的一件趣事
  3. 一个从没试过的新玩法
  4. 一个特别好用的小功能

2. 刚进小组，大家还没说话。你先来一句：

  1. “咱们今天先拍什么？”
  2. “你们想拍什么？我配合。”
  3. “我先来一段，给大家打个样。”
  4. “我先讲个拍视频的糗事。”

3. 哪种视频，你最容易点收藏？

  1. “原来这个功能这么用！”
  2. “这玩法，下次我也试试。”
  3. “太好看了，再看一遍。”
  4. “这套拍法，下次直接照着来。”

4. 朋友对着镜头一直卡壳，你会说：

  1. “别急，先歇会儿。”
  2. “看着我说，我接你的话。”
  3. “就讲你上次遇到那件事。”
  4. “咱换个机位试试。”

5. 拍完才发现没按录像。你脱口而出：

  1. “哈哈，就当彩排了！”
  2. “收音开了吗？也查一下。”
  3. “这段翻车，能当花絮！”
  4. “大家累不累？要不歇会儿。”

6. 剪视频时，你最舍不得删哪段？

  1. 路上偶遇朋友的那段
  2. 等了好久才拍到的夕阳
  3. 少了就前后接不上的那段
  4. 把功能讲得特别清楚的那段

7. 拍摄地临时关门了，你先做什么？

  1. 去旁边转转，找个新地方
  2. 打开地图，去备选地点
  3. 拉上队友，先拍段聊天
  4. 找个座位，让大家先歇歇

8. 哪条评论最让你开心？

  1. “你也太会拍了吧！”
  2. “终于看懂怎么用了！”
  3. “像朋友聊天，看着真舒服。”
  4. “这不就是我本人吗！”

9. 队友问：“这个拍法能行吗？”你会回：

  1. “试一下不就知道了！”
  2. “我演一下，你们看着。”
  3. “先看时间，来得及就试。”
  4. “给你们看张参考图。”

10. 选一种视频风格，你更想拍：

  1. 一段有头有尾的小故事
  2. 一场朋友之间的闲聊
  3. 一个简单明白的小教程
  4. 一个让人猜不到的新花样

11. 视频做好了，你先检查什么？

  1. 字幕有没有错
  2. 文件能不能正常播放
  3. 封面够不够好看
  4. 开场说话自然不自然

12. 拍完收工，哪句话最像你的感受？

  1. “跟你们一起拍，真放松。”
  2. “下次那个新玩法，必须试试！”
  3. “今天这事儿，我能念叨好久。”
  4. “跟你们接梗，笑得停不下来。”
